# 🤖 Telegram-бот «Артём» с ИИ (Google Gemini) и Веб-Панелью Управления

Полнофункциональный бот для Telegram с человечным, живым характером (на базе **Google Gemini API**), поддержкой общения в личных сообщениях и групповых беседах, возможностью занимать сторону в спорах, реагировать на имя «Артём», выполнять авто-чек-ины по расписанию и удобной веб-панелью управления, готовой к бесплатному деплою на **Vercel**.

---

## 🌟 Ключевые возможности

- 🧠 **Живой ИИ-характер (Gemini 2.5 Flash / 1.5 Flash)**:
  - Пишет как реальный человек: строчными буквами, естественным разговорным сленгом (*база, кринж, рил, жиза, ору*), без шаблонных фраз и "роботности".
  - **Выбор стороны в спорах**: не уходит от ответа, а с юмором занимает чью-то позицию и подкалывает вторую сторону.
  - Остроумно реагирует на подколы и вопросы "ты бот?".
- 🗣️ **Гибкое поведение в чатах**:
  - **В ЛС**: отвечает на любые сообщения.
  - **В беседах**: откликается на имя («Артём», «Артем», «тёма», «тема», «artem»), на `@тег`, на реплаи на его сообщения, а также имеет настраиваемый шанс (% вероятности) спонтанно вклиниться в беседу.
- 🎛️ **Веб-панель управления**:
  - Полный редактор системного промпта прямо в браузере.
  - Ползунок **Temperature** (0.0 — 2.0) и выбор модели Gemini.
  - Настройка уровня сарказма и триггеров имени.
  - 1-клик установка и проверка Telegram Webhook для Vercel.
  - Встроенный интерактивный симулятор чата (проверка характера прямо в админке).
  - История логов и список активных групп.
- ⏰ **Авто-сообщения и Чек-ины по расписанию (Vercel Cron)**:
  - Автоматические утренние, дневные или вечерние вбросы и опросы в активные группы.

## 🚀 Пошаговая инструкция по запуску и деплою на Vercel

### Шаг 1. Получите ключи

1. **Telegram Bot Token**:
   - Откройте в Telegram [@BotFather](https://t.me/BotFather).
   - Отправьте команду `/newbot`, задайте имя (например, `Артём`) и юзернейм (например, `artem_chat_ai_bot`).
   - Скопируйте полученный токен (вида `123456789:ABC...`).
   - *(Важно для групп)*: В [@BotFather](https://t.me/BotFather) отправьте `/setprivacy` -> выберите вашего бота -> выберите **Disable**, чтобы бот мог видеть сообщения в группах без обязательного тега.

2. **Google Gemini API Key**:
   - Перейдите на [Google AI Studio](https://aistudio.google.com/app/apikey).
   - Нажмите **Create API Key** (доступен бесплатно).

---

### Шаг 2. Развертывание на Vercel (За 1 минуту)

#### Способ А. Через GitHub и Vercel Dashboard (Самый простой)
1. Загрузите этот проект в свой репозиторий на **GitHub**.
2. Зайдите на [vercel.com](https://vercel.com) и нажмите **Add New Project** -> выберите ваш репозиторий.
3. В разделе **Environment Variables** добавьте переменные:
   - `TELEGRAM_BOT_TOKEN`: ваш токен от BotFather
   - `GEMINI_API_KEY`: ваш ключ от Google AI Studio
   - `ADMIN_PASSWORD`: пароль для доступа к сохранению настроек (например, `artem123`)
4. Нажмите **Deploy**.

#### Способ Б. Через Vercel CLI
```bash
npm i -g vercel
vercel
```

---

### Шаг 3. Активация бота (Привязка Webhook)

1. Откройте в браузере адрес вашего развернутого сайта: `https://ваш-проект.vercel.app`.
2. Перейдите во вкладку **«Ключи и Webhook»**.
3. Убедитесь, что поле URL заполнено (`https://ваш-проект.vercel.app/api/webhook`), и нажмите кнопку **«Установить Webhook»**.
4. Статус изменится на **«Привязан ✅»**.

🎉 **Готово!** Теперь добавьте Артёма в любую группу в Telegram, напишите ему в ЛС или тегните его в беседе.

## 💻 Локальный запуск для разработки

```bash
# 1. Установка зависимостей
npm install

# 2. Создание файла переменных окружения
cp .env.example .env.local

# 3. Запуск локального сервера
npm run dev
```

Панель управления будет доступна по адресу `http://localhost:3000`.

## 🛠️ Структура проекта

- `app/page.tsx` — Веб-панель управления (Dashboard).
- `app/api/webhook/route.ts` — Serverless обработчик входящих сообщений от Telegram.
- `app/api/cron/route.ts` — Обработчик чек-инов по расписанию (Vercel Cron).
- `app/api/settings/route.ts` — API сохранения/получения системного промпта и настроек.
- `app/api/telegram/route.ts` — Управление вебхуком и проверка статуса бота.
- `app/api/chat-test/route.ts` — Тестовая песочница для диалога с Артёмом.
- `lib/default-prompt.ts` — Эталонный системный промпт и характер Артёма.
- `lib/gemini.ts` — Клиент Google Gemini API.
- `lib/telegram.ts` — Клиент Telegram Bot API.
- `lib/storage.ts` — Хранилище настроек (в памяти + KV/Upstash).
- `vercel.json` — Конфигурация расписания для Vercel Cron.
